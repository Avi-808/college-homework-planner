# CampusFlow College Homework Planner

A browser-based college assignment planner based on the supplied College Homework Planner spreadsheet.

## Features

- Organize assignments across Monday through Sunday.
- Record courses, assignments, due dates and times, priorities, study estimates, and notes.
- Search assignments and filter by course or completion status.
- Break major assignments into individual checklist steps.
- Track completed work and see overdue assignments.
- Set a calendar reminder for each assignment and download the week as an `.ics` file to import into your calendar.
- Download a weekly CSV report or print the week.
- Save changes automatically in the current browser using local storage.

## Run it

Open `index.html` in a modern browser. No installation or account is required.

Plans are stored on the device and browser where they are entered. Calendar alerts activate after importing the downloaded calendar file into your calendar app.

## Built with

HTML, CSS, and vanilla JavaScript.
